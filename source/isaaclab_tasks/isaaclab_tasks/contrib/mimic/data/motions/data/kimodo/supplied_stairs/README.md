# Kimodo supplied stairs

Canonical G1 motion and paired stair boxes from [motion_library](https://github.com/jnskkmhr/motion_library/tree/b3132f98549f506647654a1c1bfd89410eb147ec/data/kimodo/supplied_stairs).
The NPZ is copied unchanged: 174 frames at 50 Hz, 29 joints, 35 bodies,
xyzw quaternions, and UNITREE_G1_29DOF_BALL_HAND_CFG geometry.

Source: Kimodo-G1-RP-v1 supplied example, “A person begins walking up the stairs”.
The clip ends while still moving; it does not demonstrate a prolonged stationary hold.
Source validation checks sampled contacts and joint limits, not dynamic policy tracking.
