# G1 on alpha moving MPM terrain

This standalone IsaacLab task places all robots on **one background terrain generated by `isaaclab.terrains`**. Each robot has its own bounded set of moving MPM particles and independent physics world. Particles that remain in simulated terrain retain their deformation and velocity. Recycled particles sample the shared terrain height and become fresh sand. Returning to a place does **not** restore previous tracks.

## Build warp wheel 

```bash
cd ~/isaac
test -d warp-local/.git || git clone --no-checkout https://github.com/jnskkmhr/warp.git warp-local
cd warp-local
git checkout c1204bebe3ebbf8c5fd656eafa3e5a50b4608421

uv run --no-project --python 3.12 python tools/ci/cuda_toolkit.py install \
  --version 12.9.2 \
  --platform linux-x86_64 \
  --cuda-path /tmp/isaaclab-warp-cuda-12.9.2

uv run --no-project --python 3.12 --with numpy python build_lib.py \
  --cuda-path /tmp/isaaclab-warp-cuda-12.9.2 \
  --quick &&
uv build --wheel --out-dir dist

cd ../IsaacLab
uv sync --locked --extra rsl-rl --no-install-package warp-lang &&
uv pip install --python .venv/bin/python --no-deps ../warp-local/dist/*.whl
```

## Train

```bash
uv run --no-sync --with wandb isaaclab train --rl_library rsl_rl \
  --task IsaacContrib-Velocity-Sand-G1-29dof-MPM-MovingPatch \
  --num_envs 64 --viz newton_gl --video --video_length 200
```
